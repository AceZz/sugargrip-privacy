# SugarGrip Support

Questions, bug reports, feedback, or anything else about the app:

**contact.sugargrip@gmail.com**

We read every message and usually reply within a few days.

## Common things

**My data is gone / I got a new phone.** SugarGrip stores everything on your
device only, with no account and no cloud backup. Restoring an iPhone backup that
includes app data brings it back; a fresh install starts empty.

**I want to delete my data.** Delete the app. Nothing is stored anywhere else.
